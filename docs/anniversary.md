# 一周年纪念页 (anniversary.html)

## 概述

anniversary.html 是一个恋爱一周年纪念贺卡网页，暖粉桃色调，单屏不滚动。四段式体验：

- **口令门帘**：选择"在一起那天"的月日才能进入
- **开场标题**：「一周年快乐」+ 实时计算的"在一起第 N 天"
- **漂浮照片墙**：拍立得风格照片随机散落、缓慢浮动、自动轮转，点击放大
- **结尾的话**：手写体逐字显影

整体暖粉/桃/奶油白配色 + 柔光氛围球 + 飘落花瓣，移动优先，纯静态零依赖，尊重 `prefers-reduced-motion`。

## 交互行为

### ① 口令门帘

- 两个下拉选择器：月（1-12）、日（1-31），默认空占位
- 正确月日由 `CONFIG.startDate` 推导（`correctMD()`），不另写口令，避免两处不一致
- 选对 → 门帘淡出、舞台逐段淡入；选错 → 提示 + 左右摇晃
- 按钮文案："开始"

### ② 开场标题

- 「FOR 婷 · 高世奇」+ 渐变文字大标题「一周年快乐」
- 日期范围 `2025.06.30 → 2026.06.30`
- "在一起第 N 天"：由浏览器当前日期实时计算（`daysTogether()`），含第一天

### ③ 漂浮照片墙（核心）

- 拍立得风格：暖白相纸 + 白描边 + 多层投影，轻微随机倾斜
- **随机散落 + 适度重叠**：网格抖动选位（4×3），允许叠压营造"桌上散开的照片"感
- **z-index 递增**：后出场照片永远压在先出场之上，叠压层次清晰，不会透糊
- **自动轮转**：每 2.6s 补入一张新照片、淡出最老的一张，不滚动也能循环看完全部
- **缓慢浮动**：每张照片 `translateY` 呼吸式上下浮动（GPU 合成，不触发重排）
- **点击放大**：轻点任意照片居中放大查看，点空白/✕/Esc 收回
- **拖动 + 惯性**：按住可拖动照片（`makeDraggable()`），松手带惯性滑行、摩擦衰减（`FRICTION` 0.85），碰墙边夹停，再次按下打断惯性。靠移动距离区分拖/点（< 6px 视作点击）。Pointer 事件统一鼠标与触屏；禁用浏览器原生图片拖拽（`preventDefault` + `draggable=false` + `user-drag:none`），否则 web 端按下即被原生拖图抢走事件。拖动后照片仍照常参与轮转
- **轮播开关**：右上角控制条的照片图标按钮（`Slideshow` 联动 `Wall.pause/resume`），外圈循环箭头运行时旋转、暂停时静止变灰。暂停只停定时轮转，照片仍可拖动/浮动

#### 同屏数量（`computeMax()`）

按照片墙面积自适应：`面积 / 22000`，夹在 8~12 张之间。手机与桌面一致，约 10~12 张。

#### 照片尺寸（`sizeRange()`）

按屏宽分档，占墙宽百分比：

| 屏宽 | 设备 | 照片占墙宽 |
|------|------|-----------|
| < 520px | 手机竖屏 | 30~40% |
| < 900px | 平板 | 26~34% |
| ≥ 900px | 桌面宽屏 | 20~28% |

窄屏适当放大避免小气，宽屏缩小避免拥挤；手机张数提到与桌面一致后，尺寸相应收一点防止重叠糊成一团。

#### 防漂移：预加载定方向

照片用 `new Image()` 预加载，拿到真实宽高后才创建 DOM 并加方向 class（`pw--landscape`/`pw--portrait`）。这样 `aspect-ratio` 在插入时一次定死，避免"先插入后加载导致高度突变、照片向上跳"的问题。方向完全由图片真实尺寸判断，零硬编码。

### ④ 结尾的话

- 文案在 `CONFIG.letter`，按句末标点（。！？）切成多行，每句独占一行
- 行内逐字显影（blur + 位移渐入），延迟逐字递增

### ⑤ 背景音乐（BGM）

- 音频文件 `assets/anniversary/bgm.mp3`，循环播放，默认音量 60%
- **自动播放**：借"点击开始"这次用户手势在 `unlock()` 内起播（`Music.enable()`），符合浏览器自动播放策略；个别浏览器仍拦截时按钮停在暂停态，点一下即可播
- **右上角控制条**：固定视口右上角的两个玻璃拟态圆按钮——轮播开关（照片+循环箭头）与 BGM 开关（声波柱播放时跳动、暂停时静止）；点击各自切换
- 元素缺失（如缓存旧 HTML）时安全跳过，不抛错

## 维护说明

- 页面为纯静态，无需构建
- **改纪念日**：只改 `CONFIG.startDate` 一处，口令和"第 N 天"自动跟着变
- **改结尾文案**：改 `CONFIG.letter`，会自动按句切行、逐字显影
- **换照片**：替换 `assets/anniversary/NN.jpg`，保持 `01`~`20` 命名；方向（横/竖）运行时自动判断，无需配置
- **调照片数量**：改 `computeMax()` 的分母（越小越密）和上下限
- **调照片尺寸**：改 `sizeRange()` 各档百分比
- **调轮转速度**：改 `CONFIG.rotateMs`（毫秒）
- **调拖动惯性**：改 `makeDraggable()` 内 `FRICTION`（越小越快停，0.85 较跟手）；`TAP` 是拖/点的距离阈值（像素）
- **换 BGM**：替换 `assets/anniversary/bgm.mp3`，保持文件名；改音量改 `Music.enable()` 内 `els.bgm.volume`（0~1，当前 0.6）
