> 用途：指导 `/worldcup` 点评/方案的具体打法调整，并据此重写这12场的 commentary。

## 0. 为什么要调整（一句话）

前12场已结算盈亏 -6.3、ROI -2.6%，复盘暴露三个问题：**让球在碾压场会失手、比分博冷纯撒钱、
押平局/冷门胜命中率极低**。下半场据此做三件事：**让球分场景、比分大幅压缩、胜平负基本退出**。

## 1. 复盘带来的四条核心调整

| # | 第一轮上半场做法 | 下半场调整 | 数据依据 |
|---|-----------------|-----------|---------|
| 1 | 大热场一律「让负赌赢不透」 | **按场景分化**：均势大热押让负；碾压大热改让胜或避让球 | 让负在瑞典5:1/德国7:1类碾压场必输 |

## 2. 场景分类决策树（本方针的核心）

每场先判断「大热门会小胜还是碾压」，再决定让球方向。判断依据 = 去水概率 + 双方实力差 + 首轮表现，
**不只看赔率**。

```
某方去水 ≥ 60%（大热盘）？
├─ 是 → 对手是鱼腩、实力悬殊（去水≥69% 或实力差明显）？
│       ├─ 是【碾压型】→ 押让胜（赌赢得透）/ 大球，绝不押让负
│       └─ 否【均势大热】→ 押让负（赌逼平/小胜），延续上半场最稳模式
└─ 否 → 真均势盘（极差≤12%）？
        ├─ 是 → 平局或次热项小注（仅此场景碰平局）
        └─ 否 → 中等热度，让球主菜 + 小比分副注
```

## 3. 这12场的具体分类与打法

### 3.1 碾压型大热（让负是陷阱 → 让胜+大球对冲）
- **180 阿根廷vs阿尔及利**（主69%）、**181 奥地利vs约旦**（主72%）、**182 葡萄牙vs刚果金**（主78%）
- **176 沙特vs乌拉圭**（客69%）、**185 乌兹别克vs哥伦比亚**（客70%）
- 打法：押强队**让胜**（赌赢2球+）为主菜，**但配总进球大球做对冲**——因为强队也可能只赢1球
  导致让胜失手，而大球（≥3球）与让胜正相关但不重合，强队即使打2:1、3:1，大球能兜回部分。
  **不押让负、不押小比分**。这是对上半场德国/瑞典让负翻车的修正，同时避免从"让负陷阱"跳进
  "让胜陷阱"——不把宝全押在一个方向性赌注上。

### 3.2 均势大热（让负赌逼平 → 延续最稳模式）
- **175 比利时vs埃及**（主61%）、**178 法国vs塞内加尔**（主64%）、**177 伊朗vs新西兰**（主57%）、
  **183 英格兰vs克罗地亚**（主57%）
- 打法：押热门**让负**（赌强队赢不透/被逼平）为主菜——这是上半场命中率最高的模式（巴西/荷兰/加拿大）。
  副注最多 1 个小比分。

### 3.3 真均势盘（唯一碰平局的场景）
- **184 加纳vs巴拿马**（46/30/25）
- 打法：平局赔率3.00、去水30%（平衡胜率33%≈去水，是全场定价最合理项），小注平局可玩；主菜给次热的主胜。

### 3.4 特殊场（hhad_only，仅让球/比分）
- **174 西班牙vs佛得角**（让-2）、**179 伊拉克vs挪威**（让+2）
- 打法：无胜平负可玩。174是西班牙碾压（让-2让胜1.85），按碾压型押让胜；179挪威占优，按盘口押受让方。
  **必须注明比分返还率71%最低、纯娱乐**。

## 4. 资金分配规则（每场20元）

- 主菜（让球）**12~13元**（占60~65%），方向由 §2 决策树定。
- 副注最多 2 个、共 7~8 元：碾压场押大球/让胜延伸；均势场押 1 个小比分。
- **砍掉**：多个比分博冷、押平局（真均势盘除外）、押冷门客胜。
- 校验：stake 之和必须 == 20，potential = round(odds×stake, 2)。

## 5. 守住的底线（不变）

- 点评是主观判断，非赚钱承诺，措辞避免「稳赢/必中」。
- 竞彩负和本质（返还率71%~89%，长期期望为负）贯穿所有点评——**本方针目标是「少亏、玩明白」，
  不是「能赢钱」**。复盘已证明任何优化都改不了长期期望为负。
- 让球按单关模拟判定，与真实串关规则有别（数据 single=0）。
